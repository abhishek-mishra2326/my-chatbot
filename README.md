# Saathi: AI Chatbot Web App

A public, full-stack AI chatbot website. The frontend runs in the browser, a Python backend keeps the API key secure, and responses are generated by the Google Gemini API and streamed to the user in real time.

**Live demo:** [https://my-chatbot-i8jv.onrender.com]

## Features

- Real-time streaming responses with a Stop button to interrupt generation
- Responsive chat interface for both mobile and desktop
- Dark and light themes
- Support for code blocks and lists in responses
- One-click copy button on every response and a "New chat" option
- Conversation memory, so follow-up questions work naturally
- Error handling with automatic retry and a fallback model
- Per-IP rate limiting to protect the free API quota from abuse
- User accounts with secure password hashing, and per-user chat history stored in PostgreSQL

## Architecture

```
Browser (HTML/CSS/JS)  →  FastAPI backend (Python)  →  Gemini API
```

The browser never calls the AI API directly. Only the backend does, and the API key lives in server-side environment variables, never in the frontend code or the GitHub repository.

Responses are streamed from the backend to the browser chunk by chunk using FastAPI's `StreamingResponse`, so text appears as it is generated.

## Tech Stack

- **Backend:** Python, FastAPI, Uvicorn
- **AI:** Google Gemini API (`google-genai`)
- **Frontend:** HTML, CSS, vanilla JavaScript
- **Rate limiting:** slowapi
- **Deployment:** Render
- **Database:** SQLite (local), PostgreSQL on Neon (production)

## Running Locally

1. Clone the repository and move into the folder:
   ```bash
   git clone https://github.com/abhishek-mishra2326/my-chatbot.git
   cd my-chatbot
   ```
2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   venv\Scripts\activate        # macOS/Linux: source venv/bin/activate
   ```
3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Create a `.env` file in the project root:
   ```
   GEMINI_API_KEY=your-api-key
   GEMINI_MODEL=your-model-name
   ```
   You can get a free API key from [Google AI Studio](https://aistudio.google.com/apikey).
5. Start the server:
   ```bash
   python -m uvicorn main:app --reload --port 8001
   ```
6. Open `http://127.0.0.1:8001` in your browser.

## Environment Variables

| Variable | Required | Description |
|---|---|---|
| `GEMINI_API_KEY` | Yes | Your Gemini API key |
| `GEMINI_MODEL` | No | Primary model to use |
| `GEMINI_FALLBACK_MODEL` | No | Backup model used if the primary one fails |
| `DATABASE_URL` | No | PostgreSQL connection string. If not set, a local SQLite file is used |
| `COOKIE_SECURE` | No | Set to `1` in production (HTTPS) so the login cookie is sent securely |

## Security

- The API key is stored only in server-side environment variables
- `.env` is listed in `.gitignore` and is never committed to GitHub
- Input length and message count are validated on the server
- Requests are rate limited per IP address
- The frontend renders user content safely to prevent XSS

## Limitations

- The Gemini free tier has shared daily limits across the whole app, so heavy traffic may trigger a "limit reached" message
- On Render's free plan the app sleeps after a period of inactivity, so the first load can take 30-60 seconds
